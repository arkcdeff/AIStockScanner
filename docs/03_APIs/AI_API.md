# AI API

AI explanations are generated from **existing deterministic analytics only**. The AI layer
never computes indicators, scores, or scanner logic — it narrates the numbers produced by
`AnalyticsEngine`. Every response includes the deterministic `technical_score` for auditability.

All endpoints return a JSON object with a `source` field:
- `generated` — freshly generated by the AI provider
- `cache` — served from the in-memory or `ai_explanations` cache
- `fallback` — AI unavailable or malformed; a deterministic explanation was returned instead

## Configuration

Provider is selected from environment variables (see `.env.example`):

| Env var | Purpose |
| --- | --- |
| `AI_PROVIDER` | `mock` (default) \| `ollama` \| `deepseek` \| `openai` |
| `AI_ENABLED` | set `false` to return 503 from AI endpoints |
| `AI_TIMEOUT` | request timeout in seconds (default 60) |
| `AI_CACHE_TTL` | in-memory cache TTL in seconds (default 3600) |
| `AI_OLLAMA_URL`, `AI_OLLAMA_MODEL` | Ollama endpoint + model |
| `AI_DEEPSEEK_API_KEY`, `AI_DEEPSEEK_MODEL`, `AI_DEEPSEEK_BASE_URL` | DeepSeek settings |
| `AI_OPENAI_API_KEY`, `AI_OPENAI_MODEL`, `AI_OPENAI_BASE_URL` | OpenAI settings |

## `GET /api/v1/ai/stock/{symbol}`

Explains the latest technical analysis for one stock.

**Response (AIStockExplanationResponse):**

```json
{
  "summary": "one-sentence summary",
  "medium_summary": "two-three sentence summary",
  "detailed_summary": "detailed paragraph",
  "strengths": ["..."],
  "risks": ["..."],
  "support": ["..."],
  "resistance": ["..."],
  "scanner_explanation": "...",
  "trend_explanation": "...",
  "risk_explanation": "...",
  "confidence": 80,
  "symbol": "RELIANCE",
  "company_name": "Reliance Industries Ltd",
  "trade_date": "2026-08-03",
  "provider": "mock",
  "model": "mock-analyst",
  "source": "generated",
  "technical_score": { "overall_score": 82, "trend_rating": "Uptrend", "...": "..." }
}
```

**Errors:** `404` unknown symbol or no analytics; `503` when AI is disabled.

## `GET /api/v1/ai/top-rated?limit=5`

Explains the top-rated group of stocks (by overall score, descending). `limit` 1–20.

**Response (AICollectionExplanationResponse):** `summary`, `explanation`, `strengths`,
`risks`, `opportunities`, `confidence`, `provider`, `model`, `source`, `trade_date`,
and `stocks` (list of `AnalyticsListItemRead`).

## `GET /api/v1/ai/market-summary?limit=8`

Produces a short market overview from pipeline metrics and top-rated analytics.
`limit` 1–20.

**Response (AIMarketSummaryResponse):** `summary`, `explanation`, `strengths`, `risks`,
`confidence`, `provider`, `model`, `source`, `trade_date`, `stock_count`,
and `top_rated` (list of `AnalyticsListItemRead`).

## Fallback behaviour

If the provider fails, times out, or returns malformed/empty output, the service returns a
deterministic plain-language explanation (`source: "fallback"`) rendered from the supplied
analytics. The API never returns 500 for a provider failure.

## UI integration

- Stock detail: AI card rendered server-side on `/stocks/{symbol}` and refreshed via HTMX
  partial `/stocks/{symbol}/ai`
- Dashboard: Today's AI Insights, Top Opportunities, Highest Confidence, and Recent AI
  Explanations sections
